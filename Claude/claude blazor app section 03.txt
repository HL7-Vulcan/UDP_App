In Section_03 if a section has no data then that part of the template should not be populated.  For {{ESTIMANDS_TABLE_X}} if any one of the substitutions {{...}} has a value that line should not be output and if none of the lines are populated then the entire ESTIMANDS_TABLE_X should not be populated.  Similarly if INTERCURRENTEVENTS_ROW_X has lines with no data they should be omitted and if the entire INTERCURRENTEVENTS_ROW_X is empty it should be ommited.
